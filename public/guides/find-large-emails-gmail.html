How to find large emails in Gmail

Guide · last updated 20 November 2026

Gmail's search box understands operators that filter by size, attachment type, age, and location. Combined, they let you find the emails taking the most space without opening every message.

Why large emails matter

Gmail counts the size of each message, including its attachments, toward your storage. A few large messages can use more space than thousands of short ones. Photos, presentations, and scanned documents sent to a group are common causes, and a single reply chain can repeat the same attachment many times.

The size operators

Gmail's size operators filter messages by how large they are:

OperatorWhat it findsExample
larger:Messages bigger than a sizelarger:10M
smaller:Messages smaller than a sizesmaller:100K
size:Messages around a given size in bytessize:5000000

Gmail accepts units such as K for kilobytes and M for megabytes. Treat the results as a guide: Gmail's size values are approximate, and a message's displayed size can differ slightly from the figure the operator uses.

Narrow the search with attachment and age operators

These operators help you focus on the messages that are most likely to be worth removing:

  • has:attachment finds messages that carry an attachment.
  • filename:pdf or filename:jpg finds attachments with a given file name extension.
  • older_than:2y finds messages older than two years. You can also use older_than:1y, older_than:6m, or older_than:30d.
  • newer_than: does the opposite, for messages within a recent period.
  • is:unread finds unread messages, which can help you spot mail you have never opened.
  • category:promotions finds messages Gmail has filed under Promotions. Other categories include social, updates, and forums.

Operators combine with a space between them. For example, has:attachment larger:5M older_than:2y finds older messages with attachments over five megabytes.

Search by sender or mailing list

To see whether one sender is responsible for a lot of space, search with from:. For example, from:updates larger:2M shows large messages from senders whose address contains the word updates. For mailing lists, list: matches the list identifier that many lists include in their messages.

Include Trash, Spam, and everything else

By default, Gmail's search leaves out some folders. Add in:anywhere to search across all folders, including Trash and Spam. To look only at one folder, use in:trash or in:spam. Items in these folders still count toward your storage, so they are worth checking.

Check before you delete. Open a few results before you select them. Search results can include messages you want to keep, such as tax documents, contracts, and photos of people you know.

Empty Trash and Spam

Deleting a message moves it to Trash. Trash and Spam keep messages for a limited period, which Google has described as 30 days, after which Gmail removes them automatically. To free space sooner, open the folder and use its option to empty it. Make sure nothing you need is in the folder first, because emptying is permanent.

Work in small groups

  1. Search with a size operator, and add one narrowing operator.
  2. Scan the results. Open anything unclear.
  3. Select the group you are sure about, and move it to Trash.
  4. Repeat with a different search.

Keeping each batch small makes it easier to recover from a mistake while the messages are still in Trash.

Checking the result

After you clean up, storage totals can take time to update. Check your Google account's storage page later. If you want a single view of which senders and mailing lists use the most space, Gmail Storage Lens is an open-source project that does this in your browser. It reads message headers, sizes, and labels only, and sends data only to Google. Its features are still being built, so check the project's status page before relying on them.

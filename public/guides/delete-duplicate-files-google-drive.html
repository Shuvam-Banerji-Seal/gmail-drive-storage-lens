How to find and delete duplicate files in Google Drive

Guide · last updated 20 November 2026

Duplicate files are one of the most common reasons Google Drive fills up: the same photo, export, or installer saved several times in different folders. This guide shows how to find copies, check which one to keep, and make sure the space is actually released.

Why duplicates happen

Duplicates usually come from ordinary habits. A file is downloaded again, exported twice, uploaded to a second folder, or synced from two computers. Drive keeps each copy as a separate file, and each one uses storage. Versions created by editing a file add to the total as well.

Step 1: Look for obvious copies

Start with the easy cases. Drive search can find files whose names suggest copies. Try searching for text such as copy, or for names that end in a number in brackets, such as (1). These are not proof that a file is a duplicate, because two different files can share a name, but they are a good starting point.

In list view, the details panel shows size, owner, and location for a selected file. Sorting or scanning by size can help you find large files, since duplicates of big files waste the most space.

Step 2: Use checksums when you can

A checksum is a short fingerprint of a file's contents. Two files with the same checksum are, for practical purposes, identical. Drive stores checksums for many binary file types, such as uploaded images, videos, and documents in common formats. It does not store them for native Google Docs, Sheets, or Slides files, which is one reason those are harder to compare.

Checking checksums by hand is slow. A tool that reads file metadata can group files that share a checksum in one step, and that is what Gmail Storage Lens is designed to do for Drive. Its duplicate finder is planned and is not available yet.

Step 3: Decide which copy to keep

When you have a group of identical files, keep one and remove the rest. Useful rules include:

  • Keep the newest copy, if you edited the file after making the others.
  • Keep the copy in the folder you actually use.
  • Keep the copy with the most descriptive name.

Before you remove a copy, check that it is not shared with someone who depends on it. Shared links to a removed file stop working.

Step 4: Review old versions

Many duplicates are not separate files at all. Drive keeps earlier versions of a file, and those versions can use significant space, especially for large videos or design files that change often. You can open a file's version history from its menu in Drive, and review the versions listed there.

Some versions are marked to keep forever, which stops Drive from removing them automatically. You can unmark them if you no longer need them. Google's documentation describes how many versions are kept and for how long, and that behaviour can change, so check the current help page before you rely on a specific number.

Note: Removing an old version is permanent. Download a copy first if you think you may need it later.

Step 5: Move the files to Trash

Select the copies you have decided to remove and move them to Trash. Files in Trash still count toward your storage until they are removed, and Drive keeps trashed files for a limited period, which Google has described as 30 days. If you are sure, empty Trash to release the space immediately. Check the Trash folder first so you do not remove anything you still need.

Shared drives and Workspace accounts

Files in shared drives belong to the organisation, not to an individual, and they may count toward a shared pool. If you are removing files from a shared drive, check with the other members first, and check your organisation's policy. Your administrator can also see how storage is allocated.

Files shared with you

Files that other people share with you generally do not count toward your own storage, because the owner holds them. Removing a shared file from your Drive does not delete it for its owner, but it may remove your access. Think about this before you act on shared folders.

Check the result

Google's storage page can take some time to update after you empty Trash. Check it later to confirm the change. If a large share of your storage is still used, look at the other services, because Gmail and Photos use the same quota.
